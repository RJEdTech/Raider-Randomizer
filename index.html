Raider Randomizer
Pick with names · Pick without names · Timer
⚙ Settings is where your class lists live — paste a new roster, load a saved class, or back them up. You only do this once: the Which picker row below stays on screen, and the spinner, groups, teams and seating all run off that same list.
1
Paste your class list
One name per line, or separated by commas — extra blank lines and stray spaces are ignored.
Need to get your roster? Follow this guide in the Canvas Professional Development course — it pulls an attendance roster for any section in Excel or Word, so the names are easy to copy and paste. Any list works, though: a spreadsheet column, or names you type yourself.
This protects student privacy. Your roster never leaves your computer. There is no account, no upload, and no server to send it to — the names stay in this browser, on your machine. RJ Ed Tech never receives them, never stores them, and cannot see them. Because nothing is transmitted anywhere, pasting your class list here does not share student PII with anyone. If you would still rather not use full names, first name plus last initial works just as well.
Would rather not put a roster in at all? Pick Without Names at the top of the page picks a student in every group using question cards — no list required.
2
Load the names
Puts the class into the picker so you can spin, group, team, or seat them. You only load a class once. A Which picker row appears below with all six — Spinner, Single Name, Lineup, Groups, Teams, Seating — and every one of them uses the class you just loaded. Nothing to set up again.
3
Save it so you never paste it again
Give the list a name like Period 1. It turns into a button below — one click loads the whole class, every time you open the Randomizer on this computer.
Your saved classes — click to load, ✕ to delete
No saved classes yet. Paste a list above, press Load Names, then Save as Class — it will be waiting for you tomorrow.
4
Back it up — or move it to another computer
Download one small file that holds every saved class. Keep it in OneDrive, or restore it on your laptop, your classroom computer, or a new browser to get all your rosters back in one step.
Saved classes, starred cards, your own cards, and saved decks are stored in this browser only. Clearing your browsing data, using a different computer, or switching browsers will lose them. Download a backup file and keep it somewhere safe — you can restore it here on any device.

Quick random pick — no animation

Language · Idioma · Langue
Switches the cards and this panel into Spanish or French. The rest of the Randomizer stays in English.
Working in
Groups and Pairs pick one student inside each group you already have — only the wording changes. Make groups is different: it gives the whole class one instruction that sorts everybody into new groups.
Which cards to draw from
Quick cards settle in one glance — reach for these when you just need somebody talking about the question on the board. Conversation cards are worth a minute and make a good warm-up. Or narrow it to one topic.
What the picked student does
